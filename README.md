# DevOps

## Simple HTTP Server

This project contains a simple HTTP server built with Node.js.

### Prerequisites

- Node.js installed on your system

### Running the Server

To start the server, run:

```bash
node server.js
```

Or using npm:

```bash
npm start
```

The server will start on port 3000 and you can access it at `http://localhost:3000`

The server will respond with: "Welcome to Node.js Server"
